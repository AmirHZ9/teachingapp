# ارائه کانسپت روال

صفحه‌ای فارسی و راست‌به‌چپ برای ارائه سه نمای نمونه از وب‌اپ همراه دوره. تصاویر اصلی بدون تغییر در `public/designs/` و فونت وزیرمتن به‌صورت محلی در `public/fonts/` قرار دارند. این صفحه نمایشی است و ثبت تمرین یا سرویس پشتی ندارد.

## اجرا

```bash
npm install
npm run dev
```

## خروجی انتشار

```bash
npm run build
npm run preview
```

خروجی در پوشه `dist` ساخته می‌شود. برای **انتشار دستی در Netlify، خود پوشه `dist` را آپلود کنید**. برای اتصال مخزن به Netlify نیز تنظیمات `netlify.toml` فرمان ساخت `npm run build` و پوشه انتشار `dist` را مشخص می‌کند. صفحه بدون ورود و با لینک مستقیم قابل مشاهده است و متاتگ `noindex` دارد.

گالری با کلیدهای جهت‌دار، Home و End قابل انتخاب است. نمایشگر تصویر با Escape بسته می‌شود و با دکمه‌های بزرگ‌نمایی، چرخ ماوس یا ژست دو انگشت کنترل می‌شود.
